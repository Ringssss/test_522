## Result

本轮在 `cuda:0`、`tp=1`、`prefix cache`、`block diffusion`、`threshold=0.95`、`gen_length=64` 配置下，正式 dInfer 跑通了 `LLaDA2.0-mini`。

关键结果：

- Prompt tokens: `55`
- Generated tokens: `73`
- Measured forwards: `47`
- Load time: `8.9566 s`
- Generation time: `1.9186 s`
- Throughput: `38.05 tokens/s`

模型生成出了合理的分步解题开头，说明正式推理链路是工作的。
