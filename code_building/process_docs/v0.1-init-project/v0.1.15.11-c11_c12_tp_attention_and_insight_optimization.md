## 2. C11: TP Attention（tp=4, ep=4, dp=1, 4-GPU）

### 改动
- `LLaDA2MoeAttention.__init__`: `tp_size=1` → `get_tensor_model_parallel_world_size()`
  - `self.num_heads = total // tp_size`（local heads）
  - `nn.Linear` → `QKVParallelLinear` + `RowParallelLinear`（内置 AllReduce）
  - QK norm per-head（dim=head_dim）不受 TP 影响
- `LLaDA2MoeSdpaAttention.forward()`: 删除 `//tp_size`（num_heads 已经是 local）
- `baseline_optimizations.py`: 同步删除 `//tp_size` + tuple 解包 `attn_output, _ = attn_mod.dense(...)`
- `load_state_dict()`: QKV weight 拆分为 q/k/v → weight_loader 自动 TP 切片；dense weight 用 weight_loader
- `LMHead`: nn.Linear → ColumnParallelLinear(gather_output=True)

### 关键设计决策
- 参考 Qwen3MoeAttention（per-head QK norm + QKVParallelLinear），不是 OLMoE（全局 QK norm 需要 all_gather）
- RowParallelLinear 内置 AllReduce → 不需要在 5 个 forward 路径各加手动 AllReduce
- LLaDA2.0-mini config: num_heads=16, num_kv_heads=4, head_dim=128, use_bias=False

### C11 性能（HetEval-512, batch=512, 4-GPU）
| Config | Time(s) | Fwd | ms/fwd |
|--------|---------|-----|--------|
| C5 AllReduce | 31.641 | 265 | 119.40 |
| C11-M5-K4 AllReduce | **28.070** | 269 | **104.35** |
| C11-M5-K4 AGR | 28.080 | 269 | 104.39 |
- AGR ≈ AllReduce（dp=1 时 dispatch 代码被跳过，等价于 AllReduce）

## 3. C12: dp=2 tp=4 ep=8（8-GPU 真正 AllToAll）

### 配置
```
TP Group 0: GPU 0,1,2,3 → batch[0:256]
TP Group 1: GPU 4,5,6,7 → batch[256:512]
EP Group: 全部 8 GPU → 32 experts/GPU
```

### 为什么需要 dp=2
- dp=1 时 AllToAll dispatch 被跳过 → AGR ≡ AllReduce
- dp=2 两组处理不同 input → AllToAll 真正移动 token → 负载不均衡成为真实问题

### C12 性能（batch=512, gen=256）
| Config | ms/fwd | 吞吐 |
|--------|--------|------|
| C12 naive linear placement | 74.76 | 25.7 p/s |
| C12 + popularity placement | **73.50** | 26.2 p/s |
| C12 DeepEP V1 HT | 133.06 | 弃用（CPU-GPU sync 太重）|

### 确认的 Insight
| # | Insight | 关键数据 |
|---|---------|---------|
| A | S_mask M-forward 完全静态 | within-block Jaccard=1.0, update 边界 0.97 |
| B | Block-start routing 集中→收敛 | 9/19 层显著；C12 block-start MoE 慢 45% |

### 否定的假设
- "mask routing 是模型级常量" — 跨 dataset Jaccard=0.19，跨 block=0.69
- "C11 AGR 是真正 AllToAll" — dp=1 时 dispatch 被跳过

## 6. 已排除方向（本轮新增）
| 方向 | 原因 |
|------|------|
| Shared expert MK overlap | MK async 开销 > overlap 收益 |
| DeepEP V1 HT (8-GPU) | 133 ms/fwd，CPU-GPU sync 太重 |
| Block-start proactive replication | mask routing 非模型常量 |
| decoder.decode() 跳过 softmax | raw logit ≠ softmax confidence |
