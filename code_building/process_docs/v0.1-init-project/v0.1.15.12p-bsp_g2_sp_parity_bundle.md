- A: baseline anchor。
- E: `C12-BSP-CrossLayerSP` reference，保持不变。
- G: old BSP-G reference，attention output reduce-scatter，但 attention input gather 仍在 decoder wrapper。
- G2: new SP-parity bundle。
- F: full all-reduce probe，继续作为 BSP-H/F2 上界参考。

## Decision Criteria

- Correctness/liveness: no hang, no rank path-count mismatch.
- EB invariant for C12: A/E/G/G2/F should all have `prefill_fallback=19,cold=171,hot_skip=3933,hot_update=931`.
- G2 performance target:
  - Minimum: no worse than old G beyond measurement noise.
  - Useful: stable below `69.5 ms/fwd`.
  - Strong: `68.x ms/fwd`.
- Component signal:
  - `attn.input_all_gather` should replace G's decoder-side `moe.tp_all_gather` at the attention input boundary.
  - G2 should keep `moe.bsp_chunk` near G's low count rather than E's high count.
  - MoE dispatch/combine payload is expected to remain unchanged.
- Quality:
  - Small smoke should show no catastrophic snippets.
  - Full quality set remains required before production/source downshift claim.

- Therefore G remains the measured best performance path; G2 is useful as source-downshift organization parity only if source integration needs attention to own the layout conversion boundary.

## Current Conclusion

BSP-G2 is complete as an experiment bundle.

Conclusion:

- Correctness/liveness: pass. No hang, C12 path-count invariant preserved.
- Quality smoke: pass as a smoke check. G2 snippets match G closely; no visible new degradation.
- Performance: G2 is tied with G in C12 e2e (`69.661` vs `69.676 ms/fwd`) but slower under component instrumentation (`79.786` vs `78.149 ms/fwd`).
- Attribution: G2 successfully migrates attention-input gather from `moe.tp_all_gather` into `attn.input_all_gather`, but the bytes reappear under the new bucket. It does not reduce communication bytes or synchronization points relative to G.
- Decision: keep G as the measured best performance reference. Use G2 as a source-organization/SP-parity design option only if source downshift wants attention to own both input gather and output reduce-scatter. Do not proceed to BSP-H/F2 from this result alone.
