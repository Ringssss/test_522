## Verification

- 对 `dInfer` 本地代码进行关键词检索与定点阅读，确认其基础推理主线为：
  - 生成区初始化为全 `mask_id`；
  - block-by-block 迭代；
  - 每轮通过 threshold / hierarchy 等 decoder 并行 unmask；
  - 用 prefix / dual / vicinity / block diffusion 等策略减少每步代价。
- 对 `sglang` 本地代码进行关键词检索与定点阅读，确认其 text dLLM 支持落在 `srt.dllm` 子系统，而不是临时脚本层；并验证了 `LowConfidence` 与 `JointThreshold` 两类原生算法。
- 核对了模型侧实现，确认 diffusion LLM 与 AR 的关键差异之一在于 full attention / non-causal attention 及更复杂的 KV cache 回写语义。
- 核对了官方资料，确认当前“最新实践”不是单纯做 kernel，而是同时优化：
  - step reduction
  - cache refresh
  - runtime batching / graph / parallelism

## Result

目前已经形成一份可直接服务后续研发决策的结论：

- diffusion LLM 的工程瓶颈不只是 transformer forward 本身，而是“step 数”与“每步计算范围”共同决定的乘积成本。
- 当前最有研究价值、也最容易做出系统亮点的方向，不是单独卷 kernel，而是做：
  - 动态并行解码阈值 / M2T-T2T 联动；
  - 自适应 cache 刷新边界；
  - 二者的联合控制。
- 如果只能优先做一条线，建议先做“自适应 cache 刷新 + 动态并行解码阈值”的协同优化。
