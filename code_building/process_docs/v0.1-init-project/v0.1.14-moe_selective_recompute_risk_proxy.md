# v0.1.14 — MoE Selective Recompute Risk Proxy 完整实验归档

## 归档时间：2026-04-14
## 阶段：v0.1-init-project / v0.1.14

## 1. 总体成果

本轮完成了 MoE selective recompute 的两大方向的完整 characterization：

### 方向一：Token-level Temporal Reuse
- 通过反事实单点干预(5681样本)建立了 MoE skip risk prediction framework
- token_confidence (AUC=0.900) 是最强预测器
- 组合复用预检证明单点规则不可直接迁移（误差放大5-37x）
- Layer-range sweep 发现中层(L8-L11)最安全
- 最终确定 Config-S (margin>0.90, L4-14) 和 Config-D (margin>0.70, L4-14, drift<0.02)
- 理论节省 ~8%

### 方向二：Expert-level Adaptive Pruning (top-p)
- shared expert 贡献 41.9%，routing expert 贡献 58.1%
- top-p=0.80：ΔFwd=0，42.6% expert 节省，零质量损失
- top-p=0.75：ΔFwd=-2，51.5% expert 节省，decoder 收敛更快
- top-p 完胜 fixed top-k（自适应分配更优）
- 理论节省 ~42-51%

### 两者关系
- 正交可叠加：stable token 全跳 + 非 stable token top-p pruning
- 但当前 Python hook 开销 > 计算节省，需要内联到原生代码

## 2. 关键结论

1. token_confidence/margin 是最强的 MoE skip risk 预测器（AUC 0.90）
2. 单点安全 ≠ 组合安全（误差通过 attention 层间传播累积）
3. 中层(L4-L14)是安全复用区域，浅层和深层应 fresh
4. Drift guard (shared_cos) 能解锁更激进的 margin 阈值
5. LLaDA2.0-mini 的 MoE routing 高度冗余：top-p=0.75（~4 expert）即可保持甚至提升质量
6. 去掉低权重 expert 的噪声反而帮助 decoder 收敛（ΔFwd=-2）

## 3. 待解决的工程问题
