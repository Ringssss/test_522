# v0.1.3-dInfer demo 脚本归档

## Goal

编写一个简单、可直接运行的 demo 脚本，让当前环境能够体验 diffusion LLM 的 block-wise 去噪推理流程，并输出基础速度指标。

额外约束是：

- 当前环境虽然能找到本地 dInfer 源码，但 `import dinfer` 会被缺失的 `vllm` 依赖阻塞；
- 本机没有现成的 LLaDA/LLaDA2/SDAR checkpoint 可直接做真实短跑验证；
- 因此脚本需要优先保证“现在就能运行的最小闭环”。

## Changes Made

- 新增脚本 `/home/wuhang/wuhang/dllm_wh/codex_coding/src/dinfer_dllm_demo.py`。
- 该脚本实现了一个最小可运行的 dInfer 风格推理路径：
  - `TokenArray`
  - `BlockIterator`
  - `ThresholdParallelDecoder`
  - `TraceBlockWiseDiffusionLLM`
- 脚本使用 `transformers.AutoTokenizer` 和 `AutoModelForCausalLM` 加载 dLLM checkpoint，并执行：
  - 生成区全 `mask_id` 初始化
  - block-wise diffusion decoding
  - threshold-based parallel unmasking
  - per-step trace 输出
  - 总耗时、forward 次数、tokens/s 等指标统计
- 脚本支持：
  - `--model-path`
  - `--prompt`
  - `--gen-length`
  - `--block-length`
  - `--threshold`
  - `--temperature`
  - `--mask-id`
  - `--eos-id`
  - `--trace`
  - `--show-partial-text`
  - `--metrics-output`
  - `--dry-run`
- 新增测试结果文件 `/home/wuhang/wuhang/dllm_wh/codex_coding/results/2026-04-09_dinfer_dllm_demo_smoke_test.md`，保存本轮 smoke test 结果。
