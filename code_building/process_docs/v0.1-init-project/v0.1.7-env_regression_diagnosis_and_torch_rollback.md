# v0.1.7-环境回归诊断与 torch 回退修复

## Goal

定位 v0.1.6 复验中发现的 `import dinfer` -> `std::bad_alloc` 崩溃的根因，并恢复正式 dInfer formal path 的可复现性。

## Changes Made

- 系统性诊断了 `std::bad_alloc` 崩溃的根因：
  - 确认 `torch`、`vllm`、`sglang` 各自单独导入均正常
  - 确认 `import vllm` 成功但 `import vllm.distributed` 必崩
  - 确认崩溃发生在 vllm 的编译扩展 `_C.abi3.so` 加载阶段
  - 确认与 dinfer patch、sglang、flash_attn 均无关
  - 根因：vllm 0.10.2 的 C++ 编译扩展与 torch 2.9.1 的 ABI 不兼容
- dinfer 的触发路径：`dinfer/__init__.py` -> `serving.py` -> `from vllm import distributed` -> 加载 `_C.abi3.so` -> crash
- 回退 torch 到 2.8.0+cu128（归档成功时的版本），同时配套更新 torchvision/torchaudio
- 复验正式脚本 `run_dinfer_llada2_mini.py`，确认 formal path 完全恢复

## Key Lesson

- vllm 的编译扩展 `.so` 文件与 torch 版本强绑定；torch 大版本升级（2.8 -> 2.9）会导致 vllm 的 C++ 扩展 ABI 不兼容
- 未来如果需要升级 torch，必须同时重装或升级 vllm
