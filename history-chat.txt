5. TV6 DP=1 修复详情（tv6_patch.py 三处改动）

改动 1: apply_tv6 开头手动初始化 EP group 的 all2all_manager（vllm 只在 dp>1 时初始化）
改动 2: tv6_forward_impl 中 dp_metadata is None 时创建临时 DPMetadata（vllm 只在 dp>1 时创建）
改动 3: fallback 路径（compute_mask_sp is None）加 _run_full_moe 函数——DP=1 时 orig_fn 不做 dispatch/combine 导致只有本地 64 experts 贡献，改为手动 dispatch → kernel → combine

修复后 fwd count 从 257 降到 234（fallback 输出不完整导致的多余迭代被消除），DP=2 未被破坏。

6. Attention 实现确认

- Baseline dInfer: LLaDA2MoeSdpaAttention → F.scaled_dot_product_attention
- 我们的系统: LLaDA2MoeSdpaAttention → apply_flash_attn_classic 替换 forward → 无 attn_mask 时 flash_attn_func，有 attn_mask 时 SDPA fallback
- BlockDiffusionLLM prefix cache 路径下，block 内迭代不传 attn_mask → 走 flash_attn（~95% forward）
- cross_block 和 prefill 有 attn_mask → 走 SDPA（~5%）
- SGLang: FlashInfer（ENCODER_ONLY, causal=False），只有 flashinfer 和 torch_native 可用，fa3 对 dLLM 不兼容

7. 框架机制分析

- dInfer naive_batching: 无 intra-block batch shrinking（select_undecoded 空实现），已完成序列陪跑
- dInfer dynamic_batching: 有 per-seq 异步调度（mini_batch_size），但需要 sglang backend
- Fast-dLLM: 有 block 间 batch shrinking（物理缩减 batch + KV cache slice）
- SGLang: 请求级动态调度 + Paged KV 释放，天然无陪跑；默认 max_running_requests 由用户设置
